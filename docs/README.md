## 🏗️ Architecture Overview

Playo uses a layered architecture with:
- **Models**: ObjectBox entities for data persistence
- **Providers**: Riverpod state management
- **Services**: Business logic and API communication
- **UI**: Flutter widgets and screens

## 💡 Key Concepts

- **ObjectBox**: Local database with efficient queries
- **Stable Enum IDs**: Future-proof enum persistence
- **JSON Serialization**: API communication support
- **Type Safety**: Comprehensive Dart typing throughout

## 🔧 Development Tools

- **Build Runner**: Code generation for ObjectBox and JSON
- **Riverpod**: State management and dependency injection
- **Freezed**: Immutable data classes (where applicable)
